## 4. 服务选购指南

| 类别 | 用途 | 优点 | 缺点 |
|---|---|---|---|
| 机场/中转订阅 | 日常翻墙、作为前置跳 | 便宜、节点多、低延迟中转 | 出口 IP 共享且会变、多为机房 IP |
| 静态住宅/ISP 代理 | 需要固定出口的工具 | IP 固定、ISP 类型 | 按 IP/流量计费；直连国内常不稳，需前置跳；常不支持 UDP |
| 自建 VPS | 完全可控 | 自主、可审计 | 需运维；IP 为机房类型 |

**选择标准**：稳定性（看历史可用率）> 延迟 > 是否固定 IP > 协议支持（socks5/http、UDP、能否 dialer-proxy 链） > 计费透明（无隐形限速、可退款） > **服务条款允许你的用途**。
**评估方法**：
1. `curl https://claude.ai/cdn-cgi/trace` 看 ip/loc/colo 是否稳定；多日多次一致。
2. Clash 延迟测试：`/proxies/<节点>/delay?url=http://www.gstatic.com/generate_204`，持续 < ~800ms 为宜。
3. IP 类型：ipinfo.io / 类似服务查 ASN 与类型（ISP vs hosting）。
4. 先买最短周期试用。
**价格**：本文不列价格，均 **需自行核实** 官网当期报价。
**合规**：用真实身份和真实支付方式注册；遵守服务商条款。
